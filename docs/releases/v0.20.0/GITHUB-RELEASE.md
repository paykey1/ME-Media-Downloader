# ME媒体中心 0.20.0

这一次，把媒体管理也做好。

![ME媒体中心 0.20.0 发布宣传封面](https://raw.githubusercontent.com/paykey1/ME-Media-Downloader/v0.20.0/docs/releases/v0.20.0/assets/cover.png)

从 `0.19.6` 更新到 `0.20.0`，ME 新增了完整的本地媒体工作区。下载完成的内容可以接着入库、整理、查看和导出；电脑上已有的图片、视频与音频，也能放到同一个地方管理。

## 一个地方，接住你的媒体

左侧找分类，中间看媒体，右侧读详情。新的三栏界面支持拖动宽度、折叠侧栏和调整缩略图大小。标签、备注、收藏夹和筛选条件，帮助你按自己的习惯整理；下载来源还可以按平台、博主与媒体类型查找。

![媒体库三栏：分类、网格和图片详情](https://raw.githubusercontent.com/paykey1/ME-Media-Downloader/v0.20.0/docs/releases/v0.20.0/assets/01-media-library.png)

## 下载完成，接着就能查看

下载文件完成后逐个进入媒体库，不必等整批任务结束。在传输中心查看入库状态，再跳转到对应媒体；来源信息随媒体保留。历史下载可以先预览补录范围，再把仍然存在、支持入库的文件补进来。

下载任务与上传任务各有入口，状态筛选、批量选择和文件明细集中在传输中心。下载失败与入库失败分别显示，便于找到需要处理的环节。

![传输中心：演示下载任务与入库查看入口](https://raw.githubusercontent.com/paykey1/ME-Media-Downloader/v0.20.0/docs/releases/v0.20.0/assets/05-transfer-center.png)

## 一组媒体，一起整理

- 管理模式支持整卡选择、范围选择、框选及当前筛选下的跨页全选。多选后，详情显示选中数量、记录大小和类型汇总。
- 批量添加标签、加入收藏夹或导出。收藏夹整理引用，不移动磁盘文件；智能收藏夹按已保存的筛选条件汇集媒体。
- 真实目录支持新建和移动受管文件，多存储位置便于安排不同磁盘的空间。移动有逐项进度与安全停止，停止后保留已经完成的结果。
- 单项、批量导出采用复制方式，保留库内原件；同名文件不会直接覆盖。移除软件关联与删除文件分别确认。

![管理模式：多选与整体属性](https://raw.githubusercontent.com/paykey1/ME-Media-Downloader/v0.20.0/docs/releases/v0.20.0/assets/02-batch-selection.png)

## 看图、看视频，留在当前工作区

图片查看器支持缩放、拖动、适应窗口和幻灯片播放。需要交给外部编辑器时，可以创建副本，保存后再主动导入。

视频播放器支持拖动进度、倍速、逐帧查看、保存截图与全屏；顺序、随机和单曲循环可按观看习惯切换。

![视频播放器：逐帧、倍速和截图控制](https://raw.githubusercontent.com/paykey1/ME-Media-Downloader/v0.20.0/docs/releases/v0.20.0/assets/03-video-player.png)

![图片查看器：缩放、幻灯片与编辑副本入口](https://raw.githubusercontent.com/paykey1/ME-Media-Downloader/v0.20.0/docs/releases/v0.20.0/assets/04-image-viewer.png)

## 导入在后台继续，保护方式讲清楚

导入文件夹时保留目录层级，并显示实际处理进度。关闭导入窗口后任务继续，可以从“入库任务”回来查看结果。默认复制导入，保留源文件。

新增启动密码保护与独立恢复码。可选的原地文件伪装，会可逆地改变受管文件的文件名、扩展名及隐藏属性，保持原目录，外部源文件不变。**文件伪装不是内容加密**；请妥善保存密码和恢复码，两者均丢失时不能保证恢复。

![保密与安全设置，截图中未填写任何凭据](https://raw.githubusercontent.com/paykey1/ME-Media-Downloader/v0.20.0/docs/releases/v0.20.0/assets/06-privacy-settings.png)

## 开始使用

从 [0.20.0 发布页](https://github.com/paykey1/ME-Media-Downloader/releases/tag/v0.20.0) 获取 Windows 版本。打开媒体中心，选择少量文件或一个文件夹导入，就可以开始整理；已有下载记录可从传输中心的“补录历史下载”查看。

本次正式更新的比较基线是 `v0.19.6`。先前的 `0.20.2` 为本地测试编号，不属于正式发布序列。

**已安装本地测试版 0.20.2 的用户：** 由于该版本号高于 0.20.0，程序不会自动提示此次更新。请正常退出程序后，手动运行本次 0.20.0 安装程序；不要清空用户数据目录。

多平台解析和网盘传输仍受平台登录、权限、访问限制及网络状况影响。请只保存自己有权访问和归档的内容；本次更新不改变这些访问边界。

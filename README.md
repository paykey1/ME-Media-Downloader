# ME媒体下载器

这里提供 ME媒体下载器的 Windows 安装包、SHA256 校验文件和更新说明。

请从 [Releases](https://github.com/paykey1/ME-Media-Downloader/releases) 下载最新版本。

核心功能
支持抖音、小红书、Bilibili、X、Instagram、TikTok 等平台的作品或博主内容解析。
主界面分为解析中心和下载中心，可先筛选内容、设置参数，再提交独立下载批次。
不同平台可同时下载；同一平台的批次依次执行，并可分别设置下载并发数。
下载任务、进度和日志会保存在本机。断电或程序异常退出后，重启即可选择是否继续未完成任务。
支持历史批次长期保留、整个批次重新下载，以及在旧解析内容失效时重新解析。
安装包已包含运行环境、解析组件、下载工具和 FFmpeg，安装完成后无需另外配置依赖。
支持启动时自动检查和手动检查更新；发现新版本后由用户自行决定是否安装。
这是公开测试版本，欢迎在使用过程中反馈解析、下载和界面问题。

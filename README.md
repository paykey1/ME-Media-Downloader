# ME媒体中心

在 Windows 本机完成媒体解析、传输、整理、浏览与播放。

[下载正式版与校验文件](https://github.com/paykey1/ME-Media-Downloader/releases/latest) · [0.20.0 图文说明](docs/releases/v0.20.0/README.md)

- 媒体中心：三栏管理、文件夹导入、收藏夹、智能筛选、跨页多选和整体属性。
- 图片与视频：独立查看器、播放器、照片信息、视频属性和本地导出。
- 解析与传输：支持抖音、小红书、Bilibili、X、Instagram、TikTok 等平台，下载逐文件入库，任务与进度保存在本机。
- 存储与安全：多位置管理、移动进度与安全停止、启动密码和可选文件伪装。伪装不等于加密，请妥善保存恢复码。
- 安装包内置运行环境、解析组件及媒体工具，常规使用无需另行配置依赖。

0.19.6 用户可正常升级。曾安装本地测试版 0.20.2 的用户不会收到降到 0.20.0 的自动更新提示；如需切换，请正常退出程序后手动运行本次安装程序，不要清空用户数据目录。

安装包尚未付费签名，Windows 可能显示“未知发布者”。请核对发布仓库与 SHA256 校验文件，自行确认后安装。

所有公开示意图均使用隔离演示素材；不包含用户私人媒体。第三方组件的许可证及源码出处随安装包提供。
